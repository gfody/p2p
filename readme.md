# Roots Network / Peer-to-Peer Machine Intelligence

A peer-to-peer architecture for machine intelligence that keeps models, data, and residual private while making useful structure portable, provenance-tracked, and composable.

This repository contains the engineering program, reference implementations, and the conceptual essays that define the system.
